# Kestrel releases

Notarized DMGs of [Kestrel](https://kestrel.laibe.cc), a fast, keyboard-first email client for macOS.

To install Kestrel, download the newest DMG under **Releases**. After that, Kestrel checks
<https://kestrel.laibe.cc/appcast.xml> once a day and updates itself from here.

The source code isn't in this repository.
